# Temporizador Flip Offline

Temporizador estilo reloj flip (flip clock) con:

- Animación de tarjetas que giran
- Preajustes rápidos y tiempo personalizado
- Sonidos de alarma offline (Web Audio API)
- Modo pantalla completa
- PWA / funciona offline

## Demo

https://pollococo-star.github.io/temporizador-flip/

## Uso

Abre el sitio, elige un tiempo e inicia. Funciona sin conexión después de la primera visita.
